# OpenReligion

An open source transhumanist religion with logic as it's philosophy.

We are concerning ourselves with spreading knowledge and awareness which enable people to make use of science and technology to improve their lives. There are so many things which can improve a person's life and yet there do not appear to be any documents describing all of them. This is intended to be a consolidation of many bits of research in a format which is readable to a layman.

We are also democratising things like biohacking by ensuring that substances and treatments are within reach of even the poorest of people. We rely on donations to achieve this.
